# Calculadora de Juros Compostos

Projeto desenvolvido em Python com foco no setor financeiro.

## 🚀 Tecnologias
- Python

## 💡 O que o projeto faz
Calcula o montante final e o total de juros com base na fórmula de juros compostos:
M = C * (1 + i)^t

O usuário informa:
- Capital inicial
- Taxa de juros mensal
- Tempo em meses

E o sistema retorna o montante final e o lucro em juros.

## 🎯 Objetivo
Praticar lógica de programação e criar um portfólio voltado para vagas de tecnologia em bancos.
